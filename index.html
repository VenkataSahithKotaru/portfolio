Project Overview

Smart Lender

An AI-powered loan approval prediction system that analyzes applicant information and predicts whether a loan application is likely to be approved or rejected using machine learning models.

01 — OVERVIEW

Project Overview

Smart Lender is an AI-powered web application designed to predict loan approval outcomes based on applicant and loan-related information.

The system analyzes factors such as gender, marital status, education, employment status, income, loan amount, loan term, credit history, and property area to generate a loan approval prediction.

Multiple machine learning models were evaluated, including Decision Tree, Random Forest, KNN, and XGBoost, with the trained model integrated into a Flask-based web application.

02 — PROBLEM

Problem Statement

Loan approval requires evaluating multiple applicant and financial factors. Traditional assessment processes can involve analysing several attributes before reaching an approval decision.

A predictive system can help analyze historical loan application patterns and estimate whether a new application is likely to be approved or rejected.

Smart Lender addresses this problem by applying machine learning algorithms to applicant data and providing a prediction through a simple web-based interface.

03 — OBJECTIVES

Project Objectives

  • Build a machine learning model for loan approval prediction.
  • Analyze applicant and loan-related attributes.
  • Compare multiple machine learning algorithms.
  • Evaluate model performance using training and testing data.
  • Identify the best-performing prediction model.
  • Integrate the trained model into a web application.
  • Provide real-time loan approval predictions.
  • Create a simple and user-friendly prediction interface.
04 — DATA

Dataset & Features

The model uses applicant and loan-related attributes to predict the loan approval outcome.

06 — MODEL ANALYSIS

Machine Learning Models

Multiple classification algorithms were evaluated to identify a suitable model for loan approval prediction.

  • Decision Tree
  • Random Forest
  • K-Nearest Neighbors (KNN)
  • XGBoost

Among the evaluated models, XGBoost achieved 94.7% training accuracy and 81.1% testing accuracy and was selected for integration into the application.

07 — PREDICTION

Prediction Process

  1. User enters applicant and loan information.
  2. Input values are prepared for the trained model.
  3. The trained machine learning model processes the applicant information.
  4. The system generates an approval prediction.
  5. The prediction is displayed through the Flask web interface.
